# Para + Rootstock example

A Next.js app that shows how to use the [Para](https://www.getpara.com/) wallet SDK on [Rootstock](https://rootstock.io/) Testnet. It covers:

- signing in with email, phone, Google, MetaMask or WalletConnect through the Para modal,
- showing tRBTC and tRIF balances in the modal,
- signing a message with the connected wallet.

The example lives in [`web/with-react-nextjs/para-modal-rootstock`](web/with-react-nextjs/para-modal-rootstock). Its README explains setup and how to run it.
